# 🎮 Terminal-st (Minecraft Edition)

Esta es mi versión personalizada de la terminal **st** (simple terminal) de suckless. Está optimizada para ser ligera, funcional y con una estética épica usando la fuente **Monocraft**.

## ✨ Características (Patches)
- **Ligatures**: Soporte para ligaduras de fuente.
- **Boxdraw**: Líneas perfectas para aplicaciones de consola (como htop o neofetch).
- **Xresources**: Configura colores y fuentes sin recompilar.
- **Scrollback**: Soporte para hacer scroll (usando Shift+PageUp/Down).

## 🛠️ Instalación

He incluido un script para que no tengas que pelearte con la terminal. Solo clona y ejecuta:

```bash
git clone [https://github.com/Elpepesaurio44/Terminal-st.git](https://github.com/Elpepesaurio44/Terminal-st.git)
cd Terminal-st
chmod +x install_st.sh
./install_st.sh


# 📦 Dependencias
Asegúrate de tener instaladas las librerías de desarrollo de X11 (libx11-dev, libxft-dev) y un compositor como picom si quieres efectos adicionales.
